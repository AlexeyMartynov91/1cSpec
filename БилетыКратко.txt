Билет 1
Оперативный учет: Учет товаров по складам. Списание по FIFO/LIFO (учетная политика на год) между складами. Отчет по остаткам.

Ключевые слова: Склады, FIFO/LIFO, списание между складами.

Бухгалтерский учет: Учет товаров по срокам годности. Списание по средней себестоимости, но с приоритетом товаров с наименьшим сроком годности.

Ключевые слова: Сроки годности, средняя себестоимость.

Периодические расчеты: Оклад по дням. Премия в % от оклада, зависящая от стажа. Отчет по премиям.

Ключевые слова: Оклад (дни), премия от стажа.

Бизнес-процессы: Таблица штатного расписания.

Билет 2
Оперативный учет: Пользователь вручную выбирает партию для списания в расходной накладной. Отчет по анализу продаж с расчетными показателями (интервал, срок).

Ключевые слова: Ручной выбор партии, аналитика продаж.

Бухгалтерский учет: Учет затрат на рекламу по проектам. Отчет о продажах с учетом этих затрат.

Ключевые слова: Проекты, рекламные затраты.

Периодические расчеты: Оклад по часам. Оклад может меняться несколько раз за период. Документ "Зарплата к выплате". Отчет "Расчетно-платежная ведомость".

Ключевые слова: Оклад (часы), меняющийся оклад, ведомость.

Управляемые формы: Регламентное задание на создание задач сотрудникам. Форма задачи и список задач на рабочем столе.

Билет 3
Оперативный учет: Учетная политика (FIFO/Средняя) может меняться ежемесячно. Сложное проведение при смене метода.

Ключевые слова: Смена учетной политики, FIFO/Средняя.

Бухгалтерский учет: Валютные взаиморасчеты с контрагентами по договорам. Корректировка задолженности из-за курсовых разниц.

Ключевые слова: Валютный учет, договоры, корректировка курсовых разниц.

Периодические расчеты: Совместительство. Расчет оклада по дням и командировки по часам (ставка из двух предыдущих месяцев).

Ключевые слова: Совместительство, оклад (дни), командировка (часы).

Управляемые формы: Движения контрагента в форме, комментарий с навигационной ссылкой, привязка сообщения об ошибке к полю.

Билет 4
Оперативный учет: Склады имеют приоритет. Списание происходит сначала с указанного склада, потом с других по приоритету. Себестоимость - средняя по складу.

Ключевые слова: Приоритет складов, списание по приоритету.

Бухгалтерский учет: Учет по нескольким организациям. Документ "Купля-Продажа" для перемещения между организациями (двойные проводки). Отчет-матрица.

Ключевые слова: Несколько организаций, внутренние перемещения.

Периодические расчеты: Совместительство, сменный график. Тариф по часам. Премия руководителю от фонда оплаты подразделения. Отчет "Перерасчет зарплаты" (без реализации).

Ключевые слова: Смены, тариф, премия руководителю.

Управляемые формы: Просмотр движений документа, хранение фотографии сотрудника (в базе или файле).

Билет 5
Оперативный учет: Взаиморасчеты в рублях и валютах в разрезе проектов. Автоматическое погашение авансов.

Ключевые слова: Проекты, валютные расчеты, авансы.

Бухгалтерский учет: Учет уникальных товаров по инвентарным номерам. Себестоимость - средняя по номенклатуре.

Ключевые слова: Инвентарные номера, уникальные товары.

Периодические расчеты: Совместительство. Оклад по часам, его размер зависит от шкалы по подразделению. Надбавка от продаж подразделения.

Ключевые слова: Оклад по шкале, надбавка от продаж.

Бизнес-процессы: Таблица штатного расписания.

Билет 6
Оперативный учет: Учет сборочных единиц (стеллажей). Продажа стеллажа списывает его компоненты. Использование ПВХ для характеристик стеллажей.

Ключевые слова: Сборочные единицы, ПВХ, комплектация.

Бухгалтерский учет: Учет товаров по складам и партиям. Списание по FIFO/LIFO (учетная политика на год).

Ключевые слова: Склады, партии, FIFO/LIFO.

Периодические расчеты: Расчет для автопредприятия. Фиксированная сумма, надбавка от оплат пассажиров, отпуск. Отчет "Перерасчеты зарплаты".

Ключевые слова: Автопредприятие, надбавка от выручки, отпуск.

Управляемые формы: Подбор товаров в документе с отображением цены и остатка.

Билет 7
Оперативный учет: Учет в двух валютах (рубли, доллары). Списание по партиям (FIFO/LIFO). Отчет по продажам в двух валютах.

Ключевые слова: Мультивалютный учет, FIFO/LIFO.

Бухгалтерский учет: Взаиморасчеты в рублях и евро по договорам с датой окончания. Строгое погашение задолженности (по сроку договора и хронологии).

Ключевые слова: Договоры с датой окончания, ручное закрытие валютных остатков.

Периодические расчеты: Совместительство. Ввод отработанного времени документом "Табель". Оклад по часам и командировка.

Ключевые слова: Табель учета рабочего времени, оклад (часы), командировка.

Управляемые формы: Форма подбора товаров с перетаскиванием.

Билет 8
Оперативный учет: Бюджетирование по подразделениям и статьям затрат. Контроль превышения бюджета при проведении документов.

Ключевые слова: Бюджетирование, контроль затрат.

Бухгалтерский учет: Учет уникальных товаров по инвентарным номерам. Себестоимость можно корректировать. Учет продаж в разрезе сотрудников с их свойствами.

Ключевые слова: Инвентарные номера, корректировка себестоимости, свойства сотрудников.

Периодические расчеты: Мультивалютный расчет зарплаты (USD, EUR). Тариф по часам (ставка по шкале). Надбавка за сверхурочные.

Ключевые слова: Мультивалютная зарплата, тариф по шкале, сверхурочные.

Управляемые формы: Управление видимостью реквизита "Ответственный менеджер" через функциональные опции.

Ключевые слова: Агенты, вознаграждение, валютный учет с агентами.

Периодические расчеты: Совместительство. Оклад по часам. Расчет больничного (по средней ставке за предыдущий месяц).

Ключевые слова: Оклад (часы), больничный.

Управляемые формы: Хранение фотографии сотрудника в базе данных.

Билет 11

Билет 12

Ключевые слова: Заказы покупателей, ПВХ для заказов.

Бухгалтерский учет: Учет для сборки ПК. Продажа компьютеров (со счета "Товары") и комплектующих (со счета "Материалы").

Ключевые слова: Сборка ПК, товары, материалы.

Периодические расчеты: Расчет для автопредприятия. Тариф по часам. Штраф за прогул. Компенсация на ремонт при наработке >1000 часов (требуется регистр накопления).

Ключевые слова: Тариф, штраф, компенсация за пробег (часы).

Бизнес-процессы: Таблица штатного расписания.

Ключевые слова: Комплекты, спецификация.

Периодические расчеты: Расчет по бригадам. Тариф по часам. Надбавка от продаж бригады. Премия начальнику от максимальной надбавки в бригаде.

Ключевые слова: Бригады, надбавка от продаж, премия руководителю.

Бизнес-процессы: Таблица штатного расписания.

Билет 14

Ключевые слова: Мультивалютные расчеты, авансы, оплата в рублях.

Бухгалтерский учет: Учет сборки комплектов документом "Сборка". Учет стандартной и нестандартной сборки.

Ключевые слова: Сборка комплектов, стандартная/нестандартная сборка.

Периодические расчеты: Совместительство. Ввод отработанных дней через "Табель" (флажки). Оклад по дням. Премия в % от фонда окладов подразделения.

Ключевые слова: Табель (флажки), оклад (дни), премия от ФОТ.

Управляемые формы: Динамическое изменение формы контрагента в зависимости от менеджера с использованием ПВХ.

Билет 15
Оперативный учет: Списание по FIFO/LIFO. Учет дополнительных затрат на продажу документом, которые распределяются на себестоимость.

Ключевые слова: Дополнительные затраты, распределение на себестоимость.

Бухгалтерский учет: Учет товаров по складам, партиям и характеристикам (ПВХ). Списание по FIFO/LIFO. Отчет с группировкой по характеристике.

Ключевые слова: Склады, партии, ПВХ для номенклатуры.

Периодические расчеты: Сменный график. Оклад по часам. Расчет больничного. Произвольное поощрение. Отчет в виде диаграммы Ганта.

Ключевые слова: Смены, оклад (часы), больничный, диаграмма Ганта.

Бизнес-процессы: Таблица штатного расписания.

Билет 16
Оперативный учет: Отгрузка по предоплате или в кредит (индивидуальный лимит и срок). Сложный контроль возможности отгрузки.

Ключевые слова: Кредитование покупателей, лимит, срок кредита.

Бухгалтерский учет: Списание по FIFO/LIFO (учетная политика на год). Учет порчи товара, который списывается ручной операцией.

Ключевые слова: Порча товара, ручное списание.

Периодические расчеты: Совместительство. Оклад по часам. Фиксированная компенсация за телефон. Отчет "Перерасчет зарплаты" с возможностью пересчета.

Ключевые слова: Оклад (часы), компенсация, перерасчет.

Управляемые формы: Ограничение видимости подсистем по ролям (бухгалтер, менеджер, директор) через функциональные опции.

Дополнительные задачи (2019-2020 гг.)
Оперативный учет

Трансфертные цены: Автоматическое перемещение товара из отдела закупок в торговую точку по трансфертной цене при продаже.

Комитенты: Учет товаров, принятых на комиссию. Начисление и выплата комиссионного вознаграждения.

Бухгалтерский учет

Кролики: Учет животных с весом. Учет в разрезе свойств (ПВХ). Документ "Операция" для откорма (увеличения веса).

Возврат товара: Оформление возврата от покупателя не позднее 3 дней с момента продажи.

Сроки годности + Партии: Сложный учет по партиям и срокам годности. Контроль продажи только годного товара. Списание просрочки.

Периодические расчеты

Учет рабочего времени: Документ "Учет рабочего времени" с заполнением на неделю. Расчет отпуска из среднего дневного заработка за год.

Управляемые формы

Настройка формы физ.лица: Динамическое изменение формы, закладки, отображение связанных документов.
